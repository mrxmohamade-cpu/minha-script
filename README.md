# Minha Script

تطبيق مكتبي (PyQt5) لإدارة مواعيد منحة البطالة، مع مراقبة الأعضاء وتحميل ملفات PDF وتعامل مع رسائل التفعيل.

## المميزات
- إضافة/تعديل/حذف أعضاء مع حفظ البيانات تلقائيًا.
- مراقبة دورية للمتقدمين مع إعادة المحاولة التلقائية عند أخطاء الشبكة.
- تحميل شهادات الموعد/الالتزام بصيغ PDF.
- تفعيل عبر Firebase ورسائل مدمجة داخل التطبيق.
- دعم اتجاه الكتابة من اليمين لليسار وخطوط عربية.

## المتطلبات
- Python 3.10 أو أحدث.
- تثبيت المتطلبات: `pip install -r requirements.txt` (إن وجد ملف المتطلبات)، أو تثبيت الحزم المذكورة في السورس (`PyQt5`, `requests`, `firebase-admin`).

## التشغيل
1. شغل البيئة الافتراضية (اختياري).
2. نفّذ:
   ```bash
   python main_app.py
   ```
3. يتم إنشاء ملفات البيانات والإعدادات في مجلد بيانات التطبيق الخاص بالنظام.

## المراجع
- ملفات `har_reference/` تحتوي على تسجيلات HAR للاسترشاد ببنية الـ API. **لا تقم بتعديلها.**
- سجلات التطبيق تحفظ في ملف `anem_app.log` داخل مجلد بيانات التطبيق.

## ملاحظات الجودة
- تم تعزيز تماسك الجلسة والـ headers لمضاهاة المتصفح.
- يعالج العميل أخطاء الشبكة، 429، والمهلات مع تدرج تأخيري وتسجيل واضح.
- عند تنزيل الـ PDF يتم التعامل مع الاستجابات الثنائية أو نصوص Base64 لضمان حفظ الملف دائمًا.
